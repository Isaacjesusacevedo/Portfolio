🚀 Sobre este proyecto
Este es mi portfolio personal como Desarrollador Web Junior. Lo construí desde cero para mostrar mis habilidades técnicas, proyectos personales y trayectoria profesional de forma clara, accesible y responsive.
El sitio está desarrollado con HTML5 semántico, CSS3 custom y Bootstrap 5.3, complementado con JavaScript vanilla para funcionalidades interactivas como el cambio de tema (claro/oscuro), validación de formularios y envío de emails mediante EmailJS.
💡 Cada sección del portfolio refleja mi enfoque en el código limpio, la experiencia de usuario y la documentación técnica.

🚀 Cómo ejecutar localmente
Este proyecto no requiere dependencias ni servidor. Solo necesitás un navegador web.
bash
# Clonar el repositorio
git clone https://github.com/Isaacjesusacevedo/Portfolio.git

# Entrar al directorio
cd Portfolio

# Abrir en el navegador (macOS)
open index.html

# O en Windows
start index.html

# O en Linux
xdg-open index.html
Nota: El formulario de contacto requiere una clave de EmailJS para funcionar en local. En la demo en vivo ya está configurado.

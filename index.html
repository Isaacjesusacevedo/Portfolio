Proyectos

Proyectos donde aplico buenas prácticas de desarrollo, control de versiones con Git y metodologías ágiles.

★ Destacado

Sistema Industrial

Vue 3 · TypeScript · .NET 9 · SQL Server

Gestión integral de producción semanal para fábrica de productos de limpieza: catálogo de productos, semanas laborales (lunes a sábado), carga inicial masiva, sector Tirado con registro diario de tachos y sector Armado con vista consolidada. Cálculos automáticos de stock, tachos estimados y progreso por cobertura. Backend ASP.NET Core 9 (Minimal APIs + EF Core + SPs, JWT, 34 tests MSTest) y frontend Vue 3 + TypeScript + Pinia + Element Plus, con dark mode y responsive. Reemplazó 5 años de planillas Excel (+40% productividad). En producción desde 2023.

  • Bulk create + wizard de carga inicial
  • 34 tests unitarios en verde
  • Deploy Vercel + Render + SQL Server

Sistema de Gestión Institucional

Vue 3 · TypeScript · ASP.NET Core · SQL Server

Plataforma de gestión académica del Instituto Tupac Amaru: carreras, alumnos, profesores, formularios e inscripciones. Backend en ASP.NET Core 9 con arquitectura N-Tier (AD → BR → API), autenticación JWT y hash con BCrypt, más 44 tests (MSTest + Moq). Frontend en Vue 3 + TypeScript. Proyecto en equipo.

  • Arquitectura N-Tier por capas
  • 44 tests con JWT + BCrypt

Brana — Esoteric Store

Vue 3 · ASP.NET Core · PostgreSQL · Docker

E-commerce de moda esotérica: catálogo con filtros y paginación, carrito, checkout de invitado y panel de administración con login JWT y carga de imágenes a Cloudinary. Backend ASP.NET Core 9 + EF Core sobre PostgreSQL (Supabase), desplegado con Docker.

  • Carrito + checkout de invitado
  • Panel admin con Cloudinary

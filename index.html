Sobre mí

Soy Desarrollador Web orientado a construir soluciones útiles y bien estructuradas. Me centro en escribir código limpio y mantenible, aplicando buenas prácticas de desarrollo.

Construyo aplicaciones full-stack con Vue 3 + TypeScript en el frontend y ASP.NET Core con SQL Server / PostgreSQL en el backend: APIs REST con autenticación JWT, arquitectura en capas, tests automatizados y despliegue en la nube. Uso Git para el control de versiones y sigo ampliando mi stack con Node.js y React.

Como Tutor de Programación en el Instituto Tupac Amaru (2023–2024) guié a estudiantes en proyectos reales, lo que me fortaleció en comunicación técnica, trabajo en equipo y capacidad para recibir y dar feedback. Complemento mi perfil con 5 años de experiencia en control de operaciones, donde desarrollé capacidad analítica, organización y orientación a resultados.

Sistema Industrial

Vue 3 • TypeScript • .NET 9 • SQL Server

En producción desde 2023
Gestión integral de producción semanal para fábrica de productos de limpieza: catálogo de productos, semanas laborales (lunes a sábado), carga inicial masiva, sector Tirado con registro diario de tachos y sector Armado con vista consolidada. Cálculos automáticos de stock, tachos estimados y progreso por cobertura. Backend ASP.NET Core 9 (Minimal APIs + EF Core + SPs, JWT, 34 tests MSTest) y frontend Vue 3 + TypeScript + Pinia + Element Plus, con dark mode y responsive. Reemplazó 5 años de planillas Excel (+40% productividad).
